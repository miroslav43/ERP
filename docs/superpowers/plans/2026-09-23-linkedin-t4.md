# LinkedIn T4 — plan de implementare

> **Pentru execuție:** inline, în sesiune (CLAUDE.md: fără fan-out de agenți).
> Pașii folosesc `- [ ]` pentru urmărire.

**Scopul:** pagina de firmă pornește pe 29 sept cu lotul 1 gata de urcat, situl
anunță pilotul pentru contabili și se leagă de pagina de LinkedIn, iar loturile
2–7 au un flux repetabil.

**Arhitectura:** două schimbări mici în stratul de marketing (`sameAs`, secțiunea
pilot pe `/pentru-contabili`), conținutul în `docs/comercial/linkedin/`,
vizualurile într-o pânză Claude Design, livrarea către Miro printr-o pagină-kit
(Artifact) cu text de copiat și fișiere de descărcat.

**Tehnologii:** Next.js 16 (Server Components, `next/link`), Vitest, Claude
Design (tipul „Design”), Artifact cu `assets`, Playwright (doar ca rezervă la
export).

**Spec:** `docs/superpowers/specs/2026-09-23-linkedin-t4-design.md`

## Constrângeri globale

- Română cu ș/ț cu virgulă (U+0219/U+021B); testul „nicio sedilă turcească” le
  verifică în tot stratul de marketing.
- **Nicio sumă în lei scrisă de mână** în `src/content/landing/**` sau
  `src/app/(marketing)/**` — testul „orice sumă scrisă în copy vine din tabelul
  canonic” o respinge. Comisionul se scrie ca procent.
- Pilotul: **10 cabinete · înscrieri până pe 15 nov 2026 · gratuit până pe
  31 mar 2027 · 20% timp de 6 luni din prima lună plătită**.
- `sameAs`: `https://www.linkedin.com/company/144846087/` — adresa publică, NU
  cea de administrare (`/admin/dashboard/`).
- Lanțul de verificare al sesiunii: `pnpm typecheck && pnpm check:server && pnpm
lint && pnpm test`. **Fără `pnpm build`** (memoria `erp-fara-build-de-la-mine`).
- Git: `git commit --only -- <căi>`, `git merge origin/main`, push pe `main`.
- Cifrele din postări se verifică în `src/content/legal/*.ts` și, pentru
  calendar, cu `sarbatoriAnului()` — nu din spec, nu din memorie.

## Focusul revizuirii

1. **Adresa de administrare lipită în `sameAs`.** Miro a dat
   `…/company/144846087/admin/dashboard/`; un `sameAs` spre o pagină care cere
   autentificare e o afirmație falsă pentru crawler. → testul din Task 1 respinge
   orice profil care conține `/admin`.
2. **Pilotul rămâne afișat după 15 noiembrie.** Pagina e statică; o secțiune cu
   termen expirat promite ceva ce nu mai există. → testul din Task 2 cade la 7
   zile după termen, cu mesaj care spune ce e de făcut (prelungire sau scoatere).
3. **Datele din textul pilotului se despart de constante.** Cineva prelungește
   termenul în `PILOT` și uită textul. → Task 2: textul e construit din
   constante, iar testul verifică că data formatată apare în copy.
4. **O sumă în lei strecurată în copy-ul pilotului** („29,80 lei pe lună”). →
   acoperit de testul existent al tabelului canonic; Task 2 îl rulează.
5. **Linkul-îndemn duce la o rută care nu există.** → testul existent
   „legăturile interne duc undeva”; Task 2 îl rulează după adăugarea linkului.

- [ ] **Pas 1: testele care cad**

```ts
describe("pilotul pentru contabili", () => {
  it("textul e construit din constante, nu scris de mână", async () => {
    const { PILOT, PILOT_CONTABILI, dataPilot } = await import("./pentru-contabili");
    const tot = [
      PILOT_CONTABILI.titlu,
      PILOT_CONTABILI.lead ?? "",
      ...PILOT_CONTABILI.pasi.map((p) => p.text),
    ].join(" ");
    expect(tot).toContain(dataPilot(PILOT.inscrieriPanaLa));
    expect(tot).toContain(dataPilot(PILOT.gratuitPanaLa));
    expect(tot).toContain(`${PILOT.comisionProcent}%`);
    expect(tot).toContain(`${PILOT.comisionLuni} luni`);
    expect(dataPilot("2026-11-15")).toBe("15 noiembrie 2026");
    expect(PILOT.inscrieriPanaLa < PILOT.gratuitPanaLa).toBe(true);
  });

  it("un pilot închis nu rămâne anunțat pe site", async () => {
    const { PILOT } = await import("./pentru-contabili");
    const toleranta = 7 * 24 * 60 * 60 * 1000;
    const inchis = Date.now() > Date.parse(`${PILOT.inscrieriPanaLa}T23:59:59Z`) + toleranta;
    expect(
      inchis,
      `înscrierile s-au închis pe ${PILOT.inscrieriPanaLa}: prelungește PILOT.inscrieriPanaLa sau scoate secțiunea de pe /pentru-contabili`,
    ).toBe(false);
  });

  it("pagina afișează secțiunea și duce la formular", () => {
    const sursa = readFileSync("src/app/(marketing)/pentru-contabili/page.tsx", "utf8");
    expect(sursa).toContain("PILOT_CONTABILI");
    expect(sursa).toContain('href="/cere-demo"');
  });
});
```
