## Reguli de scris

- Nicio cifră legală care nu e deja pe sit, cu articolul lângă ea.
- Nimic care sugerează experiență pe care n-o avem („amenzile pe care le vedem”).
- Nu se copiază textul de pe sit. 150–250 de cuvinte, un caz concret, o întrebare.
- Primele două rânduri opresc derularea — atât se vede înainte de „…mai mult”.
- Max 3 hashtag-uri. Linkul în primul comentariu, cu UTM:
  `?utm_source=linkedin&utm_medium=social&utm_campaign=t4-NN-<subiect>`.
- Subiectele marcate ⚠ în `NOTES.md` nu se explică public până nu sunt
  confirmate (azi: plafonul lunar al diurnei).
